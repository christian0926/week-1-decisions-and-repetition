# Oppgave 04 — Crystal Classifier

**Hovedfokus:** if / else if / else

Et ukjent krystallmateriale klassifiseres etter energiverdien:

- under 20 → `Dormant`
- 20–49 → `Stable`
- 50–79 → `Unstable`
- 80 eller mer → `Critical`

Bruk **én sammenhengende `if / else if / else`-struktur**.

Test minst `0`, `19`, `20`, `49`, `50`, `79`, `80`, `130`.

## Kjøring

```bash
dotnet run
```
