# Oppgave 10 — Probe Launch Slots

**Hovedfokus:** for-løkke

Et probesystem skal skrive ut nummererte utskytningsluker.

Bruk en vanlig `for`-løkke til å skrive:

```text
Launch slot 1 ready
Launch slot 2 ready
...
Launch slot 8 ready
```

Utvid deretter løsningen slik at `firstSlot` og `lastSlot` bestemmer intervallet. Test med `3` til `6` uten å endre selve løkkelogikken.

## Kjøring

```bash
dotnet run
```
