# Oppgave 03 — Reactor Window

**Hovedfokus:** ranges og &&

En reaktor fungerer normalt når energinivået er mellom **40 og 70, inkludert begge grensene**.

Lag `isStable` som ett bool-uttrykk.

Krav:
- Bruk to sammenligninger.
- Kombiner dem med `&&`.
- Ikke løs oppgaven med flere separate `if`-setninger.

Test: `39`, `40`, `55`, `70`, `71`.

## Kjøring

```bash
dotnet run
```
