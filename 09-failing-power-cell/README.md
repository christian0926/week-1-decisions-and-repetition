# Oppgave 09 — Failing Power Cell

**Hovedfokus:** while-løkke

En skadet kraftcelle mister `drainPerCycle` prosentpoeng for hver syklus.

Bruk en `while`-løkke som:
- skriver gjeldende charge
- reduserer charge
- stopper når charge er `0` eller lavere

Pass på at programmet ikke går i en evig løkke.

Test f.eks. `charge = 23`, `drainPerCycle = 5`.

## Kjøring

```bash
dotnet run
```
