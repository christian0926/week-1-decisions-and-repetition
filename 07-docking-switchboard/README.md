# Oppgave 07 — Docking Switchboard

**Hovedfokus:** tradisjonell switch

Et gammelt dokkingssystem mottar en tekstkode.

Bruk en **tradisjonell `switch` statement**, ikke switch expression.

Regler:
- `NORTH` → `Dock at gate 1`
- `EAST` → `Dock at gate 2`
- `SERVICE` → `Dock at maintenance bay`
- `CLOSED` → `Hold position`
- alt annet → `Unknown docking code`

Test alle fem typer input.

## Kjøring

```bash
dotnet run
```
