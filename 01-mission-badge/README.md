# Oppgave 01 — Mission Badge

**Hovedfokus:** string interpolation

Du arbeider på et gammelt romskipssystem som lager en tekstlinje til hvert besetningsmedlem.

Bruk variablene som allerede finnes i `Program.cs` og lag **én string** kalt `badge` med string interpolation.

Krav:
- Bruk `$"..."`.
- Ikke bruk `+` for å sette sammen teksten.
- Resultatet skal ha nøyaktig format:

```text
PILOT: Rhea | SHIP: Halcyon | SECTOR: K-19
```

Bytt deretter verdiene på variablene og bekreft at teksten oppdateres automatisk.

## Kjøring

```bash
dotnet run
```
